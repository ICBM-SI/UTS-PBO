## Deskripsi Program
Program berikut merupakan contoh program penyewaan baju profesi sederhana yang menerapkan (Command Line Interface) menggunakan bahasa pemrograman Java dengan menerapkan prinsip Pemrograman Berorientasi Objek.

## Alur Program
### 1. Menu Utama
Menu Utama merupakan tampilan awal saat program pertama kali  dijalankan. Menu utama memiliki 3 opsi pilihan seperti opsi melihat daftar baju yang dapat disewa, opsi melakukan penyewaan, dan opsi keluar dari program.

<img width="293" height="124" alt="Screenshot 2026-09-27 205526" src="https://github.com/user-attachments/assets/e9b70c09-bd51-499c-aedc-cd7ad4a8b4f2" />

Jika pengguna memasukkan input angka yang tidak tertera pada opsi, maka program akan melakukan looping dengan memberikan peringatan sebelum kembali ke menu.

<img width="295" height="258" alt="Screenshot 2026-09-27 205547" src="https://github.com/user-attachments/assets/5dbc9534-e02d-48a0-bce5-c35942321882" />

### 2. Lihat Daftar Baju
Opsi ini digunakan jika pengguna ingin melihat daftar baju/seragam yang dapat disewa, program akan menampilkan nomor ID baju, jenis, nama baju, nama profesi, dan harga sewa.

<img width="305" height="415" alt="Screenshot 2026-09-27 205558" src="https://github.com/user-attachments/assets/4f72ad4f-a900-4d9c-8fbc-efe3a98f34c4" />

### 3. Sewa Baju
Jika user ingin melakukan penyewaan baju, user harus mengisi beberapa data seperti nomor ID baju yang ingin disewa, nama penyewa, dan lama sewa yang dihitung per-hari. Jika input sudah sesuai, maka program akan menampilkan struk penyewaan diakhir.

<img width="295" height="414" alt="Screenshot 2026-09-27 205620" src="https://github.com/user-attachments/assets/7b77eb99-b259-4e72-920f-05281dbf2558" />

### 4. Keluar
Jika program sudah selesai digunakan, opsi keluar akan mengakhiri program dan memberikan ucapan "Terima Kasih".
